OOHDASH-146 addendum: "Who's calling?" start screen (D15) and the caller banner (D16)

Revision 4.3 of the design. Every frame below is a real screen from the clickable prototype, drawn with the live stylesheet, in the state named in its label. Frames are static pictures you can scroll inside; to click through the whole call, open the full prototype (it starts on this new screen, and the "Caller banner" control at the top lets you switch the banner state on any screen).

What changes. "New call" opens "Who's calling?" with the customer's name, role and number and the site search on one screen. The details are optional: the agent can go straight to the site search, and the call record still starts when the site is confirmed. Once the site is confirmed, a permanent banner shows on every in-call screen: the caller's name, number and role if given, and the site. Four states: full details; partial (name only or number only); none taken (quiet "No contact details taken" with an optional "Add details" that never blocks); and updated when details are added mid-call. The banner is display only inside the signed-in session. Customer contact data is still held only on the Zendesk ticket, with the 12 month automatic deletion and manual removal from PD-1.
