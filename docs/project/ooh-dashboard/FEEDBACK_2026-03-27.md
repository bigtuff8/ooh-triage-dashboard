# OOH Dashboard — User Feedback 2026-03-27

Detailed feedback from James during prototype testing session. All items to be addressed.

## Structural UX

1. **Back button on all flows** — permanently available, agent might click wrong option
2. **Escalation UX overhaul:**
   - When a flow reaches escalation, explain to the agent what's about to happen BEFORE the modal
   - Give a basic script to discuss with the customer while they review/add notes
   - After submitting escalation, the new messages (script etc.) need to be more prominent/obvious — currently blends in
3. **Modal close = stuck state** — closing escalation modal without submitting leaves no options. Must always have a route forward.

## Flow Intelligence — Remove Agent Interpretation

4. **Too Cold: auto soft-pushback** — system has the data (temp vs setpoint), so it should determine if pushback is appropriate automatically. No "if temperature is close..." — tell the agent what IS.
5. **Kitchen schedule review** — "Is a schedule causing the issue?" requires interpretation. The system should compare live data to the customer's need and explain it: "The schedule shows OFF at this time. We can override." No question.
6. **Keeps Turning Off: which equipment?** — ask which equipment FIRST. Not all equipment has an interlock panel. Flow assumes interlock exists.

## Content Completeness

7. **Controls/Salus USB step** — add "No cable available / can't try this" option
8. **Salus icon walkthrough** — add supporting graphics so agent and caller know exactly what icons look like
9. **Kitchen equipment list incomplete** — only references fryers, ovens, grills. Missing: bain maries, heated gantries, extraction fans, Merrychefs, dishwashers, glasswashers. Expand significantly.
10. **"Other" catch-all** — both problems and equipment need robust catch-all routes to escalation. Agent must never be stuck.
11. **External heating missing** — outdoor heaters need a category. Under Heating or under External (alongside lighting).
12. **Binary action validation** — after instant actions (turn on lights, override switch), need a "Did it work?" confirmation step. If not → escalate. Don't let the call end without validating. Apply to heating/fryer flows too where there's a delay — tell agent to set expectations with caller.
