# OOH Triage Dashboard — Handler's Guide (design gate)

This gate presents the finished hi-fi Handler's Guide for review. The plain-English summary above is the product to read; this body is a short record of the deliverable.

## The deliverable

A single self-contained web page — mockups/bau-support-guide.html — embedded above as the live prototype. It opens in any browser with no install, works on a phone, adapts to light or dark, and is built to print cleanly for the PDF stage that follows. All 28 screenshots are inlined into the file, so it is fully portable.

## Audience and intent

Written for non-technical out-of-hours handlers. It blends a training guide, a step-by-step procedure and a frequently-asked-questions set, in plain English with no technical vernacular. It documents the live tool as it behaves today (version 1.2.4) and nothing that is not yet live.

## Notes for the reviewer

- Every picture is a genuine dashboard screen; the engineer-only status strip has been removed from each so handlers are not shown internal wording.
- A few engineer-only pop-up screens were left out and described in plain words instead.
- Change-to-equipment actions are described as "the request is logged and the team will action it", with no internal detail.

Approve to advance to the PDF stage, or request changes.
